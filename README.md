# KsenovКэф

Android-приложение для водителей такси/курьеров: показывает текущий
коэффициент спроса (surge) на карте в виде градиентной тепловой зоны,
запрашивая данные напрямую у sprostaxi.ru — без собственного бэкенда.
Поддерживает постоянно обновляющийся плавающий виджет поверх других
приложений.

## Возможности

- **Карта спроса.** Тап в любую точку — сетка сэмплов вокруг неё,
  радиус разбивается на соты (гексагоны), каждая раскрашивается по
  коэффициенту, интерполированному по сэмплам; границы сот не сплошные,
  а плавно растушёваны, чтобы соседние ячейки визуально перетекали друг
  в друга. На каждой сэмплированной точке отдельно подписан её реальный
  коэффициент (фиолетовая молния + `xN`), размер шрифта подстраивается
  под реальное расстояние между точками на экране, чтобы подписи не
  наезжали друг на друга.
- **Такси / Курьер.** Переключение между тарифами одним контролом.
- **Геолокация.** Определение текущего положения с классической
  android-эвристикой "точность + свежесть" вместо наивного "самый
  свежий таймстемп" — устраняет типичный баг с неточным
  `NETWORK_PROVIDER`, перебивающим точный GPS-фикс.
- **Плавающий виджет.** Компактная таблетка с текущим коэффициентом
  поверх любого приложения, обновляется по таймеру, цветом сигнализирует
  об ошибке получения данных.
- **Персистентность.** Последняя позиция карты, масштаб, радиус запроса и
  выбранный тариф сохраняются между запусками.
- **Кэш тайлов.** Явно настроенный дисковый кэш карты — повторные визиты
  в тот же город не требуют повторной загрузки тайлов.
- Только реальные данные — режима "демо/mock" нет; при сбое запроса
  приложение честно показывает ошибку, а не подставляет случайные числа.

## Стек

- **Kotlin** + **Jetpack Compose** (Material 3) — UI
- **osmdroid** — карта на тайлах OpenStreetMap, без ключей Google
- **OkHttp** + **kotlinx.coroutines** — сетевой слой
- **SharedPreferences** — персистентные настройки
- Foreground **Service** + `WindowManager` — виджет поверх экрана
- Никакого бэкенда: всё, включая rate-limiting и разбор ответов
  sprostaxi.ru, выполняется прямо на устройстве

## Требования

- Android Studio (Koala/Ladybug или новее)
- Android SDK, JDK — устанавливаются автоматически вместе со студией
- minSdk 24, compileSdk/targetSdk 34

## Сборка

1. **File → Open** → выбрать корень проекта.
2. Дождаться Gradle Sync (при первом открытии студия может предложить
   восстановить Gradle wrapper и/или апгрейд AGP/Kotlin — соглашаться).
3. **Build → Generate App Bundles or APKs → Generate APKs**, либо ▶ Run
   на подключённом устройстве/эмуляторе.
4. Собранный файл: `app/build/outputs/apk/debug/app-debug.apk`.

Иконка приложения ссылается на `@mipmap/ic_launcher` /
`ic_launcher_round` — свою можно подставить через
**Android Studio → New → Image Asset**.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `INTERNET`, `ACCESS_NETWORK_STATE` | Запросы к sprostaxi.ru, загрузка тайлов карты |
| `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` | Определение текущего положения (карта, виджет) |
| `SYSTEM_ALERT_WINDOW` | Плавающий виджет поверх других приложений |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_LOCATION` | Работа виджета в фоне (Android 14+) |
| `POST_NOTIFICATIONS` | Уведомление foreground-сервиса виджета (Android 13+) |

Разрешения запрашиваются по месту использования, а не все разом при
старте.

## Ограничения запросов

sprostaxi.ru — небольшой бесплатный инструмент без авторизации, не
собственная инфраструктура проекта. У него объявлен лимит
10 запросов / 10 секунд; клиент придерживается 8/10с с запасом
(`SlidingWindowRateLimiter`) и использует общий на всё приложение
экземпляр клиента (`AppServices`), чтобы карта и фоновый виджет не
считали бюджет независимо друг от друга. Интервал обновления виджета
ограничен снизу 10 секундами намеренно — выставить чаще нельзя.

Если планируется распространять сборку за пределы одного устройства —
стоит свериться с условиями использования sprostaxi.ru: APK на многих
телефонах суммарно создаёт кратно больше запросов, чем локальное
тестирование одним человеком.

## Известные ограничения

- Шрифт — системный (Roboto), настроенный по начертаниям под целевой
  визуальный стиль; точный кастомный шрифт не подключён.
- Данные только для реального времени — исторических графиков/аналитики нет.
